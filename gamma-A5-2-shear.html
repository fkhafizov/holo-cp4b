Γ(A₅, 2): two holograms, one shear

For the path tree A₅ = P₅ (vertices 1–2–3–4–5, rooted at 1) with k = 2 tokens there are two pictures of the same state X. The tree hologram from the paper is a k × (n−1) = 2 × 4 grid whose column eᵢ is filled to height ηᵢ(X) = number of tokens beyond the cut eᵢ. The lattice-path hologram is a staircase path in the (n−k) × k = 3 × 2 rectangle: read the word left to right, 0 = step east, 1 = step south. They are the same object. Row r of the tree picture belongs to one token, and its length is (#0's before the token) + (#1's before the token). The lattice path counts only the 0's. Since the number of 1's before a token is fixed by the token's rank (k − r), deleting it is a rigid horizontal shift of each row. Think of a deck of cards pushed sideways: every card (row) slides by its own fixed amount, no card changes length, so row-by-row differences between two decks — the distance — are untouched.

Why the two pictures agree

  • Tree hologram: ηᵢ(X) = #{tokens at positions > i}, for edges eᵢ = {i, i+1}, i = 1,…,n−1.
  • Let the token positions be q₁ < q₂ < … < qk. Row r (counted from the bottom) of the η-grid is filled exactly in columns i ≤ qk−r+1 − 1, so its length is ℓr = qk−r+1 − 1 = (#0's before the token) + (#1's before the token).
  • The lattice path in the (n−k) × k box gives row length λr = #0's before that token. Since #1's before it is k − r, we get ℓr = λr + (k − r): shifting row r left by k − r turns the η-grid into the Young diagram λ(X), and the η step profile into the lattice path.
  • Cell bookkeeping: k(n−1) = C(k,2) frozen + k(n−k) free + C(k,2) unreachable. For n = 5, k = 2: 8 = 1 + 6 + 1. The free cells form a parallelogram that the shear straightens into the 3 × 2 box.
  • Area: Σᵢ ηᵢ(X) = |λ(X)| + C(k,2). Distance: d(X,Y) = Σᵢ |ηᵢ(X) − ηᵢ(Y)| = Σr |ℓr(X) − ℓr(Y)| = Σr |λr(X) − λr(Y)| = |λ(X) △ λ(Y)|.
  • Consequently Γ(An, k) is the Hasse diagram of the lattice L(k, n−k) of partitions in the box, and diam Γ(An, k) = k(n−k) (empty box ↔ full box).
  • Contrast with D₅: there the last two η-columns are independent leaf bits (x₄, x₅) instead of the suffix sums (x₄+x₅, x₅). The rows of the η-grid are no longer "one token each", so no row shear produces a rectangle; the maximal pair 11000 → 00011 has area 5 instead of 6.

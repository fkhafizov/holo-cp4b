Shortest paths in Γ(T, k) as fillings of the hologram

Each move in a tree token graph changes exactly one column of the hologram by one cell. A shortest path from X to Y has length d = Σₑ|ηₑ(X) − ηₑ(Y)|, so every column moves monotonically and every cell between the two profiles is toggled exactly once. Writing the step number into the cell it toggles gives a standard filling of the difference region, much like writing 1, 2, 3, … into a Young diagram. Every shortest path gives such a filling, and every admissible filling (one where each prefix is a legal hologram) gives back a shortest path. For Aₙ, after the row shear, the admissible fillings are exactly pairs of skew standard Young tableaux. For Dₙ the fork adds one twist: the two leaf cells act like a glued domino.

Diameter and number of extremal geodesics

Diameter pair X = {1,…,k}, Y = {n−k+1,…,n}. diam Γ(Aₙ,k) = k(n−k); diam Γ(Dₙ,k) = k(n−k) − 1 for 2 ≤ k ≤ n−2. In Aₙ the number of geodesics is f(n−k)ᵏ (hook length formula). In Dₙ it is 2·e(Pₖ,ₘ), where Pₖ,ₘ is the k × m rectangle (m = n−k) with one corner cell removed. For k = 2 this is 2·Cn−3.

The statements

  • Any tree. Shortest X→Y paths ↔ admissible standard fillings of the difference region R(X,Y) of the hologram: labels 1,…,d, monotone up each growing column and down each shrinking column, with every prefix a legal hologram (0 ≤ x_v ≤ 1 at every vertex).
  • Aₙ. With λ = λ(X), μ = λ(Y), ν = λ ∩ μ: N(X,Y) = C(d, |μ/ν|) · fμ/ν · fλ/ν. Removals and additions never interact, so a geodesic is a shuffle of a skew SYT of λ/ν (read backwards) with a skew SYT of μ/ν.
  • Dₙ. Fold the two leaves into one site holding s = xn−1 + xn ∈ {0,1,2}. The folded states are Young diagrams in the k × (n−k) box in which the vertical domino in the last column, rows 1–2, is added or removed in one move. If the two leaf bits do not swap: N = m · C(p+q, p) · fdom(μ/ν) · fdom(λ/ν), with m = 2 when both leaves flip the same way (00 ↔ 11) and m = 1 otherwise. If they swap (10 ↔ 01): N = e(Qdip) + e(Qbump), where the path either empties both leaves for a while or fills both for a while.

Self-Reversal Distance Atlas

Self-reversal distance in consecutive-cycle graphs

For a word X with k zeros and n−k ones, let X* be X read backwards and ρl(X) = dGl(X, X*). Holographically, reversal rotates the lattice path by 180° inside the k×(n−k) rectangle, so ρ measures how far a path is from being centrally symmetric. Every count below comes from exhaustive computation over all words.
